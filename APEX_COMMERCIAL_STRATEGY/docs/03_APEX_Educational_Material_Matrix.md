## What to teach each persona

### Persona A — Executive Decision Makers
| Question | Answer |
|---|---|
| What should we teach them? | Know-how is an asset you can organise, prove and scale. |
| What problem should we highlight? | Expertise trapped in people and folders. |
| Which APEX capability should we showcase? | Playbook → course → verifiable certificate; one front door. |
| Which infographic should we create? | Executive infographic (Poster 01, 09) |
| Which video or presentation should we prepare? | 3-minute business value video |
| What should they understand afterwards? | APEX turns knowledge into measurable capability with low risk. |
| What action should they take next? | Name a sponsor and approve a pilot. |
| Message to deliver | “Your expertise is your product. APEX makes it findable, teachable and provable.” |
